# Shaka site (Docusaurus)

Run commands from the repository root:

```bash
npm run install:site   # install dependencies
npm run prepare        # sync docs from shakacode/shaka and prepare them
npm run dev            # local dev server
npm run build:site     # production build into prototypes/docusaurus/build
```

`docs/` here is generated by `npm run prepare`; edit docs in `shakacode/shaka` instead.
